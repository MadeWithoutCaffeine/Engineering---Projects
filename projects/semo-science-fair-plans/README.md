## Background

In eighth grade, I investigated how airplane-wing shape affects lift and received a Naval Science Award at the SEMO science fair. I'd like to return with the CAD, 3D printing, programming, and engineering experience I've gained since then.

I have more projects and tools to work with now. The part I still need to decide is which question would make the best investigation and fit the time I have.

## Rough approach

I want to choose a question I can test well, rather than pick a project only because I already have something built. I would define what changes, what I measure, and what needs to stay consistent, then plan repeated trials and keep a record of the results.

If I use work from Non-Trivial or a team project, I would first check the fair's requirements for that work and explain each person's contribution. Before starting an experiment intended for the fair, I would check any required forms or approvals with my teacher.

For a possible senior-year entry, I could investigate a new question or extend earlier work with a clearly defined new experiment. I haven't decided which direction to take.
